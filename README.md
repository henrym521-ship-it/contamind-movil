# ContaMind · Fotos de facturas

Página para el teléfono de **ContaMind PRO**: un teléfono autorizado desde ContaMind (computadora → «Teléfonos → Invitar un teléfono») toma fotos de facturas y las sube a la carpeta privada de la cuenta. La computadora las recibe en «Recepción».

- El teléfono **solo puede subir fotos**: no ve facturas, montos ni reportes.
- No contiene datos de clientes ni claves secretas (solo la llave *publicable* de Supabase, hecha para ir en apps).
